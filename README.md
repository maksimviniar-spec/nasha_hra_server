# Наша гра — сервер (початкова онлайн-версія)

Це початковий сервер для онлайн-кімнат гри «Наша гра». Він підготовлений для Node.js та Render.

## Що вже є
- перевірка роботи сервера: `GET /health`;
- список відкритих кімнат: `GET /api/rooms`;
- створення кімнати та приєднання за кодом;
- до 4 гравців у кімнаті;
- нікнейми та статус готовності;
- власник кімнати може почати матч;
- базовий канал обміну станом матчу й ігровими діями через Socket.IO;
- дві назви мап: «Мапа 1» і «Мапа 2».

## Важливо про поточний етап
Цей серверний пакет — основа онлайн-кімнат. Наявний HTML-файл гри поки що не підключений до Socket.IO: для цього потрібна окрема зміна клієнтського HTML-коду. Повна серверна перевірка бойових дій, синхронізація хвиль/ворогів/бійців, облікові записи та постійне збереження прогресу ще не реалізовані.

Пам'ять безкоштовного вебсервісу може очищатися після перезапуску, тому кімнати зараз тимчасові. Не використовуй цей початковий сервер як систему збереження монет або інвентарю.

## Локальний запуск
Потрібен Node.js 20 або новіший:

```bash
npm install
npm start
```

Потім відкрий `http://localhost:10000/health`.

## Публікація на Render через GitHub
1. Завантаж усі файли цієї папки в корінь репозиторію GitHub `nasha_hra_server`.
2. На Render створи **Web Service** і підключи цей репозиторій.
3. Render має визначити Node. Команди: Build `npm install`, Start `npm start`.
4. Після публікації перевір адресу сервісу з кінцівкою `/health`. Має повернутися JSON з `"ok": true`.

Файл `render.yaml` містить ці налаштування автоматично.

## Оплата
У коді немає платіжної системи, платіжних ключів або покупок. Не вводь платіжні дані заради цього ігрового сервера. Доступність безкоштовного тарифу Render визначається самим Render і може змінюватися.
